# 7.2 Graph Query

## What Does This Do?

> **Provides semantic, filtered lookups over an existing `Graph` — the readable API layer on top of the raw graph maps.**

While the `Graph` data structure itself exposes raw maps (`nodes`, `edges`, `outgoingEdges`, `incomingEdges`), working with them directly requires callers to write their own edge-kind filtering and node-kind checks every time. `GraphQuery` abstracts that repetition into named, semantically meaningful methods.

It answers questions like:
- *"Which symbols call this function?"*
- *"Which files does this file import?"*
- *"What npm packages does this file import?"*
- *"Which classes extend this base class?"*
- *"What does this node directly depend on?"*

## Class Signature

```ts
class GraphQuery {
    constructor(private readonly graph: Graph) {}
}
```

`GraphQuery` takes a `Graph` at construction and exposes read-only methods over it. It never mutates the graph — it is a pure query facade.

## Method Groups

### Group 1: Primitive Queries

Raw access methods that hydrate edge IDs or node IDs into full objects. These are the building blocks for all higher-level queries.

---

#### `getOutgoingEdges(nodeId: string): GraphEdge[]`

Returns all `GraphEdge` objects for edges leaving `nodeId`.

```ts
getOutgoingEdges(nodeId: string): GraphEdge[] {
    const edgeIds = this.graph.outgoingEdges.get(nodeId);
    if (!edgeIds) return [];

    return [...edgeIds]
        .map((edgeId) => this.graph.edges.get(edgeId))
        .filter((edge): edge is GraphEdge => edge !== undefined);
}
```

**What it does internally**: Looks up `outgoingEdges.get(nodeId)` to get the Set of edge IDs, then hydrates each ID into a full `GraphEdge` object from the primary `edges` map. The `filter` with a type predicate drops any edge IDs that don't resolve (which shouldn't happen after validation, but makes the type safe).

---

#### `getIncomingEdges(nodeId: string): GraphEdge[]`

Symmetric to `getOutgoingEdges`. Returns all `GraphEdge` objects for edges arriving at `nodeId`.

```ts
getIncomingEdges(nodeId: string): GraphEdge[] {
    const edgeIds = this.graph.incomingEdges.get(nodeId);
    if (!edgeIds) return [];

    return [...edgeIds]
        .map((edgeId) => this.graph.edges.get(edgeId))
        .filter((edge): edge is GraphEdge => edge !== undefined);
}
```

---

#### `getNode(nodeId: string): GraphNode | undefined`

Single node lookup by ID. Returns `undefined` if the node doesn't exist.

```ts
getNode(nodeId: string): GraphNode | undefined {
    return this.graph.nodes.get(nodeId);
}
```

---

#### `getNodesByKind(kind: GraphNodeKind): GraphNode[]`

Returns all nodes of a given kind (`"file"`, `"symbol"`, `"dependency"`, `"module"`).

```ts
getNodesByKind(kind: GraphNodeKind): GraphNode[] {
    const nodeIds = this.graph.nodesByKind.get(kind);
    if (!nodeIds) return [];

    return [...nodeIds]
        .map((nodeId) => this.graph.nodes.get(nodeId))
        .filter((node): node is GraphNode => node !== undefined);
}
```

Uses the `nodesByKind` index built by `GraphBuilder` — O(|nodes of that kind|), not O(all nodes).

---

### Group 2: Derived (Semantic) Queries

Each method answers a specific named relationship question. All of them read incoming or outgoing edges, filter by `relationshipKind`, and check the target/source `node.kind` to return the correct node type.

---

#### `getCallers(nodeId: string): GraphNode[]`

**Question**: *Who calls this symbol?*

Walks **incoming** edges with `relationshipKind === "calls"`, returns symbol nodes that are the sources of those edges.

```
A → calls → [nodeId]     ← getCallers returns [A]
```

```ts
for (const edgeId of this.graph.incomingEdges.get(nodeId) || []) {
    const edge = this.graph.edges.get(edgeId);
    if (!edge || edge.relationshipKind !== "calls") continue;

    const callerNode = this.graph.nodes.get(edge.sourceId);
    if (callerNode && callerNode.kind === "symbol") callers.push(callerNode);
}
```

**Returns**: `GraphNode[]` — only symbol nodes (functions/methods that call this node).

---

#### `getCallees(nodeId: string): GraphNode[]`

**Question**: *What does this symbol call?*

Walks **outgoing** edges with `relationshipKind === "calls"`, returns symbol nodes that are the targets.

```
[nodeId] → calls → B, C     ← getCallees returns [B, C]
```

---

#### `getPackageDependencies(nodeId: string): GraphNode[]`

**Question**: *Which npm packages does this file import?*

Walks **outgoing** `"imports"` edges and returns only `DependencyNode` targets (not file nodes, not module nodes).

```
[fileNode] → imports → "express" (dependency node)   ← returned
[fileNode] → imports → "./utils" (file node)          ← filtered out
[fileNode] → imports → "fs"     (module node)         ← filtered out
```

```ts
if (!edge || edge.relationshipKind !== "imports") continue;
const dependencyNode = this.graph.nodes.get(dependencyNodeId);
if (dependencyNode && dependencyNode.kind === "dependency") packageDependencies.push(dependencyNode);
```

---

#### `getImporters(nodeId: string): GraphNode[]`

**Question**: *Which files import this node?*

Walks **incoming** `"imports"` edges and returns only `FileNode` sources — the files that have an import statement pointing to this node.

```
fileA.ts → imports → [nodeId]    ← getImporters returns [fileA]
fileB.ts → imports → [nodeId]    ← getImporters returns [fileB]
```

---

#### `getImportedFiles(nodeId: string): GraphNode[]`

**Question**: *Which internal files does this file import?*

Walks **outgoing** `"imports"` edges and returns only `FileNode` targets — the source files this file imports (as opposed to npm packages or modules).

```
[fileNode] → imports → "./auth.ts"  (file node)     ← returned
[fileNode] → imports → "express"    (dep node)      ← filtered out
```

---

#### `getBaseClasses(nodeId: string): GraphNode[]`

**Question**: *What does this class extend?*

Walks **outgoing** `"extends"` edges, returns symbol nodes (the parent class or classes).

```
class Child extends Parent  →  [Child] → extends → [Parent]
getBaseClasses(Child) returns [Parent]
```

---

#### `getSubclasses(nodeId: string): GraphNode[]`

**Question**: *Which classes extend this class?*

Walks **incoming** `"extends"` edges, returns symbol nodes (the subclasses).

```
class Child extends Parent  →  [Child] → extends → [Parent]
getSubclasses(Parent) returns [Child]
```

---

#### `getImplementedInterfaces(nodeId: string): GraphNode[]`

**Question**: *Which interfaces does this class implement?*

Walks **outgoing** `"implements"` edges, returns symbol nodes (the interface definitions).

```
class Foo implements IFoo  →  [Foo] → implements → [IFoo]
getImplementedInterfaces(Foo) returns [IFoo]
```

---

#### `getImplementations(nodeId: string): GraphNode[]`

**Question**: *Which classes implement this interface?*

Walks **incoming** `"implements"` edges, returns symbol nodes (the implementing classes).

```
class Foo implements IFoo  →  [Foo] → implements → [IFoo]
getImplementations(IFoo) returns [Foo]
```

---

#### `getDependentNodes(nodeId: string): GraphNode[]`

**Question**: *What does this node directly depend on (across all dependency relationship types)?*

Walks **outgoing** edges filtered against all structural dependency kinds:

```ts
const dependencyRelationshipKinds = new Set([
    "calls", "imports", "extends", "implements", "instantiates"
]);
```

Returns any node type (file, symbol, dependency, module) that this node has any structural relationship with, regardless of relationship kind. This is the broadest direct-dependency query.

---

#### `getDependents(nodeId: string): GraphNode[]`

**Question**: *Which nodes directly depend on this node (across all dependency relationship types)?*

The reverse of `getDependentNodes` — walks **incoming** edges filtered against the same dependency relationship kinds, and returns the source nodes of those edges.

## Relationship with the Analytics Engine

`GraphQuery` is the **single-hop** query layer — every method returns only direct neighbors. The analytics engine (section 8) builds multi-hop analysis on top of the raw `Graph` maps directly (not through `GraphQuery`), because algorithms like BFS, Tarjan's SCC, and Kahn's sort require direct index access for performance.

`GraphQuery` is therefore primarily used by:
- API controllers that need to look up a node's immediate callers, callees, or importers in response to a UI request.
- Future serialization or export layers that need to enumerate nodes by kind.

---

## Design Decisions

**Return `GraphNode[]` not `GraphNodeKind[]`**: Methods return hydrated node objects, not just IDs. This means callers get the full payload (name, symbolKind, filePath, etc.) immediately, without a second lookup.

**Node kind filtering on every derived query**: Every semantic method explicitly checks `node.kind` before pushing to its result array. This is defensive — even if a bug upstream adds a wrongly-typed edge (e.g., a `"calls"` edge between two file nodes), the query will not silently return a file node from `getCallers`, which is supposed to return only symbol nodes.

**`dependencyRelationshipKinds` is a module-level constant**: The set of structural dependency kinds used by `getDependentNodes` and `getDependents` is declared as a `const Set` at module scope, not inside the class. This avoids reallocating the Set on every method call. The same pattern is used in `DependencyOrderingAnalyzer`.
